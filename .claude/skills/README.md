# Project skills

Claude Code loads every `SKILL.md` under this folder for sessions in this repository.

| Skill | Source | Use |
|---|---|---|
| `jazz-lick-validator` | This project | Lesson data format (single source for notation, tab, fretboard, audio), alphaTab rendering, and the validator every lick and standard must pass |
| `web-design-guidelines` | Vercel (pinned snapshot) | Accessibility, focus, forms, motion, typography and touch review of UI code |
| `react-best-practices` | Vercel | React / Next.js performance rules |
| `composition-patterns` | Vercel | Component API design (compound components, no boolean-prop sprawl) |
| `react-view-transitions` | Vercel | Native view-transition animations between screens |

Each vendored skill has a `SOURCE.md` with its upstream commit and license. Not added from
vercel-labs/agent-skills: `deploy-to-vercel`, `vercel-cli-with-tokens`, `vercel-optimize` (deploy
and billing tooling, and the CLI-token skill handles credentials), `react-native-skills` (this is
a web app) and `writing-guidelines` (Vercel's own docs house style).
